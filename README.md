## 亮点

- **随机种族** —— 三套种族开局 / 运营策略随机切换，一条命令开打
- **自研对局诊断指标** —— PBR / RUR / APU / TR 四项核心指标每局实时输出，JSONL 落盘可复盘
- **实时监控台** —— 对局画面与指标并存，边打边看
- 基于 python-sc2

## 状态

持续迭代中（五项新机制已落地，向稳定击败作弊三推进）。
